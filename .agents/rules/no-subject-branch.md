# No Subject Branch / Discipline

**Rule**: Do not add, reference, or use "Subject Branch" or "Discipline" (e.g., Physical, Organic, Inorganic) as a filtering mechanism, form field, or display property anywhere in the application (including the admin portal and the student portal).

**Context**: The user explicitly requested to completely remove the Subject Branch/Discipline concept from the platform. Any newly created components, forms, or data structures should avoid implementing or relying on this classification.
